# Radar 2.0 — Fase 1 (Esperando você + resumo do dia + funil) — Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Radar vira "central do dia": fila nova "Esperando você" (clientes sem resposta) no topo, resumo do dia em linguagem humana, seletor de funil + busca, seções colapsáveis. Sem migration, sem chamada nova de LLM.

**Architecture:** endpoint do radar ganha a fila `esperando_voce` (query sobre `last_customer_message_at > last_agent_message_at`), filtro opcional `pipeline_id` em todas as filas e um objeto `resumo` com os números do dia; a página é reorganizada com header narrativo + seletor de pipeline + busca client-side + seções colapsáveis. Spec: `docs/superpowers/specs/2026-08-26-radar-2-design.md` (Fase 1).

**Tech Stack:** o de sempre (NestJS/Prisma; Next/RQ/shadcn). Jest API para as queries; web verifica com tsc+build+visual.

## Global Constraints

- NUNCA `any`. Jest `--maxWorkers=2`. `tsc --noEmit` nos dois apps; `npm run build` no web.
- Visibilidade: TODAS as filas continuam passando por `buildVisibilityWhere` (o teste pool-mode do OR continua valendo — não quebrar).
- Linguagem humana no front (nada de "insight", "score", "IA sugere" seco); conteúdo de LLM sempre texto React puro.
- `esperando_voce`: `last_customer_message_at` não-null E (`last_agent_message_at` null OU < `last_customer_message_at`), etapa ativa (não ganho/perdido), ordenado por `last_customer_message_at` ASC (quem espera há mais tempo primeiro), cap 30, dedupe COM PRECEDÊNCIA MÁXIMA (lead em esperando_voce não aparece nas outras filas).
- `pipeline_id` opcional filtra todas as filas (query param validado: string uuid; ausente = todos os funis).
- `resumo` calculado no backend com os dados já buscados (zero query extra além de 1 agregação): `{ esperando: n, chamar_hoje: n, valor_chamar_hoje: soma, lembrete_destaque: { nome, motivo } | null }` — destaque = 1º item de chamar_hoje (mais atrasado) se houver.
- Branch `feat/radar-2-fase-1` de `master`. Commits `feat(api):`/`feat(web):`.
